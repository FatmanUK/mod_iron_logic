# Structural arc and motifs — Iron Logic

An industrial press executes an unyielding rule. Its load changes, its responses become heavier, and the final stroke ends the operation.

A is a four-pattern C-minor working cycle, including one B-flat diversion. B moves through A-flat and B-flat, then returns to C without reducing the ensemble. Repeated A and B cycles build inevitability through context. C is a one-time four-pattern release route, ending in a tom-led final press stroke.

Tonal language: C minor with A-flat and B-flat transfer states.

| Motif | Identity |
| --- | --- |
| Ram stroke | Kick and FilterBass strikes leave a broad gap for the half-time snare. |
| Rule word | A compact C–G–E-flat buzzer signal, answered rather than sustained. |
| Die marker | WoodBlock and low filter marks distinguish the press states without adding a fifth voice. |
| Last compression | Tom and snare intervals contract into a final full-level C stroke. |

## Phrase vocabulary

These are authored thirty-two-row melodic fragments. Pattern tables are the build source. A fragment may hand its reply to another sample as described in the pattern notes; each event is still one note. Times below are decimal row offsets.

| Fragment | Events: row / trigger |
| --- | --- |
| a | 00/C-5, 06/G-5, 12/D#5, 22/D-5, 28/C-5 |
| b | 02/G-5, 10/D#5, 18/C-5, 26/A#4 |
| c | 00/A#4, 07/D-5, 14/F-5, 22/D-5, 28/A#4 |
| d | 00/G#4, 08/C-5, 14/D#5, 22/C-5, 28/A#4 |
| e | 02/D#5, 06/G-5, 10/F-5, 18/D#5, 24/D-5, 28/C-5 |
| f | 00/C-5, 04/C-5, 12/G-5, 18/D#5, 26/C-5 |
| g | 00/F-5, 08/D#5, 14/C-5, 22/G#4, 28/C-5 |
| h | 02/D-5, 08/F-5, 14/G-5, 22/F-5, 28/D-5 |

The named motif is developed by changing which fragment answers it, the underlying bass state, and the percussion handoffs. The first group begins with the complete working ensemble. Repeated groups return at full identity; there is no default empty breakdown and gradual rebuild. The terminal group is used once, and its coda has separately authored events.
